# Credit image

`edited-with-take-studio.png` is the "Edited with Take Studio" credit laid over a free creator's video (spec 0026). It is made by `pnpm credit:png` (`scripts/render-credit-png.ts`), never by hand: 1000 px wide, white text on a 60% black box, transparent rounded corners.

`InterTight-Variable.ttf` is Inter Tight, the typeface of the app, used only to draw that text. It is licensed under the SIL Open Font License 1.1 (https://openfontlicense.org), which allows bundling it.
