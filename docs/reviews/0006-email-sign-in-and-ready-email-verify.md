## Worth knowing

- A used link only reaches the friendly page when the link was requested from the form (it carries `errorCallbackURL`). A link requested straight from the API, as Jim did, lands on the home page with an error code. Nothing in the app requests links that way.
- The "sent" state shows the address the creator typed. That is fine for the creator, and the same text appears for any address.
