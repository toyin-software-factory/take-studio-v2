## Gaps found, and how they were closed

1. **AC-9 check could not see the libraries (closed).** My first version of the build output check passed on a build made before #133, when `gsap` and `lenis` were not installed, so it passed only because there was nothing to find. CodeRabbit rightly asked for the claim to be corrected. After #133 merged I rebuilt, and found the library signatures (`GreenSock`, `gsap.registerPlugin`, `ScrollTrigger`, `CustomEase`, `lenis-smooth`, `lenis-stopped`, `Lenis`) in exactly one client chunk. `tests/pages-v2.spec.ts` now has a positive control (the signed out homepage's scripts must carry a marker, so the check cannot pass by being blind) next to the real check (the scripts a signed in `/` and take page load carry none). `three` is not a dependency.
2. **Browser failures in my first long run (not code, closed).** The first full run on the earlier build had 104 passes and 10 failures: the transcript specs (8), `shell.spec.ts` sign out (1) and the first test of `background-picker.spec.ts` (1). On a fresh preview of the merged build the transcript and shell specs pass (25 of 25). The picker test failed because two leftover studio rows from my earlier killed runs gave it two "Calm studio" radios in the local database; I removed those two test rows and all 18 picker tests pass. The long run on a sandbox with 3 GB of memory also slowed down over time, which is why those specs timed out at the end.
